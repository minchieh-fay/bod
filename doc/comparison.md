# 策略对比

| 项目 | v0.1.0 | v0.2.0 / 当前 main |
|---|---|---|
| 订单数量 | 同时一个程序订单 | 多层 BUY/SELL 网格 |
| 价格层级 | 单一 spread | `1A、3A、5A...` |
| 成交后的动作 | 反向挂单 | 按两侧数量和层号管理网格 |
| 连续单边成交 | 不适用或需等待反向单 | BUY/SELL FIFO 队列暂存 |
| 价格移动适应 | 反向单定时重校准 | 不对称时重校准订单较多的一侧 |
| 收益配对 | 相邻 BUY/SELL | FIFO 按成交数量配对 |
| 适合场景 | 简单、低复杂度验证 | 多层波动捕捉和网格交易 |

新策略不是保证盈利的套利策略，而是受 `layers × quantity` 约束的双边网格。收益和风险主要取决于振幅、层数、成交顺序、手续费、资金费率以及行情是否持续单边移动。
